# Problem (mask_pii): Personally identifiable information (3 points)
## (d)
分布偏移 / 不自然文本：大量重复的占位符 token 会破坏语言的自然分布，模型可能学会大量生成 |||EMAIL_ADDRESS||| 这种串，或在本该出现联系方式的语境里产出占位符。
误伤（false positive）：正则会误替换非 PII（如版本号 1.2.3.4、代码里的 @decorator、时间/编号），破坏正常文本语义。
上下文断裂：邮箱/电话常出现在"联系我们"等结构化语境，全抹掉后这些句子失去信息、变得残缺。

缓解方法（题目要求提到 mitigation）：
用多样化的替换（如加随机后缀、或用合成的假邮箱替代固定占位符），保持文本自然度；
收紧正则、结合上下文降低误报；
控制遮蔽比例 / 只在高置信度时遮蔽。

# Problem (harmful_content): Harmful content (6 points)
## (c)
- 没法做专门判定harmful内容的模型。正当含敏感词的也会误判；
- 方言/群体偏见：这类分类器对 AAVE（非裔美式英语）等方言的误报率更高，naively 过滤会不成比例地删掉特定群体的语言，放大数据偏差。
缓解：
- 置信度阈值，非0，1
- 多信号/人工抽检校准阈值
- 保留一小部分，兼顾安全和能力
