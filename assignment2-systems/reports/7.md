# Problem (fsdp): expected peak memory savings
## （a）
FSDP 把参数、梯度、优化器状态全部按 `1/n` 分片，每类各省 `(n-1)/n`；在 `n=2` 的口径下，这三类常驻状态从每卡 `16·N ≈ 51984 MB` 降到 `8·N ≈ 25992 MB`，即每卡省约 **26 GB**（忽略 all-gather 临时 buffer）。但激活值（≈15 GB）不被分片、完全不节省，因此峰值从 step 后转移到 fwd+bwd 阶段（激活主导），实际全局峰值约从 52.7 GB 降到 ~28 GB，即每卡实降约 **24 GB**。
