# Problem (think_about_length_normalization): Think about length normalization (1 point)

按每条序列自身长度进行归一化，相当于计算每个 token 的平均奖励或损失，因此不同长度的序列可以直接比较，较长的回答也不会仅仅因为 token 更多而产生更大的更新。这种方法适合希望每个 prompt 具有相近影响力的情况，尤其适用于长度不同的回答之间进行偏好比较。但它可能会过度强调较短的序列，而较短序列的平均值通常方差更高；同时，较长序列的重要信息也可能被低估。使用同一个常数归一化则会保留 token 级别的贡献，使较长序列按 token 数量贡献更多，适合希望每个 token 权重相同或 rollout 长度固定的语言模型训练。缺点是长序列可能主导整个 batch，而且结果会受到所选常数的影响；如果更关注不同样本之间的公平性，应采用按序列长度归一化，否则统一常数归一化可能更合适。

# Problem (think_about_rft): Think about RFT (2 points)
设 $s_j=\nabla_\theta\log\pi_\theta(y^{(j)}|x)$，并记 $a=\mathbb{E}[r(y|x)s]$。RFT 梯度的期望是 $Ga/Z$。由于 Dr. GRPO 使用的是同一组样本的均值 $\mu=G^{-1}\sum_j r_j$，且 $\mathbb{E}[s]=0$，其梯度期望为 $(G-1)a/Z$，因此在当前的归一化写法下二者并不完全相同，只相差一个 $(G-1)/G$ 的缩放因子；如果使用 leave-one-out mean 或相应地重新调整 $Z$，则可以恢复相同的期望方向。

Dr. GRPO 通常方差更低，因为组均值作为 baseline 会减小奖励的共同部分；对于二值奖励，它不仅强化成功样本，也会对同组中的失败样本产生负的相对优势。RFT 在正奖励稀疏、希望直接保留所有成功样本的场景下更直观，尤其是 $G$ 较小的时候；Dr. GRPO 则适合 $G>1$ 且更关注降低方差、利用组内相对质量的场景。不过，如果一组样本全部成功或全部失败，Dr. GRPO 的优势为零，会丢失绝对奖励信号，而 RFT 仍能从成功样本中学习。

# Problem (derive_difficulty_reweightings): Advantage normalizers

记
$$
p(x)=\mathbb{E}_{y\sim\pi_\theta}[r(y|x)],\qquad s(y,x)=\nabla_\theta\log\pi_\theta(y|x).$$
由于 $\mathbb{E}_{y\sim\pi_\theta}[s(y,x)]=0$，有
$$
\mathbb{E}_y[(r(y|x)-p(x))s(y,x)]
=\mathbb{E}_y[r(y|x)s(y,x)].
$$
因此只需比较不同归一化因子对每个 prompt 的缩放。

## (a) Dr. GRPO

当 $G\to\infty$ 时，组均值 $\mu$ 收敛到 $p(x)$，所以式 (41)（取 $Z=G$）收敛为
$$
\mathbb{E}_{x\sim\rho}\left[\mathbb{E}_y[(r-p(x))s]\right]
=\mathbb{E}_{x\sim\rho}\left[\mathbb{E}_y[r s]\right].
$$
这正是标准 policy gradient，因此对应的重加权函数为
$$
\boxed{w_{\mathrm{Dr.GRPO}}(x)=1}.
$$

## (b) 标准差归一化的 GRPO

二值奖励在 $G\to\infty$ 时的组标准差为
$$
\operatorname{std}(r|x)=\sqrt{p(x)(1-p(x))}.
$$
故式 (42) 变为
$$
\mathbb{E}_{x\sim\rho}\left[
\frac{1}{\sqrt{p(x)(1-p(x))}}\mathbb{E}_y[r s]
\right],
$$
对应的 prompt 重加权为
$$
\boxed{w_{\mathrm{GRPO}}(x)=\frac{1}{\sqrt{p(x)(1-p(x))}}}.
$$
这会相对放大成功率接近 $0$ 或 $1$ 的困难/容易 prompt 的更新，并相对减小 $p(x)\approx 1/2$ 的 prompt 的权重；实际实现中通常需要加入 $\epsilon$ 以避免标准差为零。

## (c) MaxRL

当 $G\to\infty$ 时，组均值 $\mu$ 收敛到 $p(x)$，因此式 (43) 变为
$$
\mathbb{E}_{x\sim\rho}\left[
\frac{1}{p(x)}\mathbb{E}_y[(r-p(x))s]
\right]
=\mathbb{E}_{x\sim\rho}\left[
\frac{1}{p(x)}\mathbb{E}_y[r s]
\right].
$$
所以对应的重加权函数为
$$
\boxed{w_{\mathrm{MaxRL}}(x)=\frac{1}{p(x)}}.
$$
它会强烈强调当前成功率较低的 prompt，即更偏向困难问题；当 $p(x)=0$ 时该归一化未定义，实际训练需使用 $\epsilon$ 或跳过这类 prompt。式中的 $w$ 应理解为 stop-gradient 权重，因此不对 $p(x)$ 本身求导。

# Problem (think_about_advantage_normalization): Think about advantage normalization

按组标准差归一化可以使 advantage 的尺度更加稳定，降低不同 batch 或不同 prompt 的奖励尺度差异对梯度大小的影响，通常有利于训练稳定；但它会改变不同 prompt 的相对权重，并且当一组样本的奖励几乎全相同时，标准差很小会放大噪声，标准差为零时还需要加入 $\epsilon$。按组均值归一化相当于使用相对成功率，成功率较低的困难 prompt 会获得更大的权重，因此适合希望优先学习困难问题的场景；缺点是当组均值接近零时方差很大，甚至可能数值不稳定。完全不做 advantage 归一化能够保留绝对奖励信号，不会因归一化而产生额外的 difficulty reweighting，在奖励稀疏或需要区分“全部成功”和“全部失败”的组时更直观；但它缺少对不同 prompt 梯度尺度的控制，梯度大小可能随 prompt 难度和奖励分布大幅变化，从而导致较高方差，或使高奖励、高方差的 prompt 在训练中占据更大影响。

## 实验结果分析

16 个 run（4 种方法 × seeds 1–4）均已跑满 200 步。最终 validation accuracy 如下（值 1024 例中的正确数占比；崩溃 run 计入统计，与 `plot_grpo_variants.py` 的均值一致）：

| 方法 | seed 1 | seed 2 | seed 3 | seed 4 | 全 seed 均值 | 全 seed 标准差 |
| --- | --- | --- | --- | --- | --- | --- |
| `GRPO_constant` | 0.423 | 0.451 | 0.448 | **0.062（崩）** | 0.346 | 0.164 |
| `Dr_GRPO` | 0.462 | 0.439 | 0.445 | 0.428 | **0.444** | **0.012** |
| `RFT` | 0.429 | 0.400 | 0.411 | 0.412 | 0.413 | 0.010 |
| `MaxRL` | 0.424 | 0.407 | 0.470 | **0.067（崩）** | 0.342 | 0.160 |

**平均性能（两种统计口径）**：

- **含崩溃 seed（全 4 个 seed 均值，与绘图 `summary.json` 一致）**：`Dr_GRPO`（0.444）> `RFT`（0.413）> `GRPO_constant`（0.346）> `MaxRL`（0.342）。此排序受崩溃 run 强烈影响：`GRPO_constant` 与 `MaxRL` 各有一个 seed 崩溃到 ~0.06，把均值拉低到 0.34。
- **剔除崩溃 seed（只统计未崩溃 run）**：`Dr_GRPO`（0.444）> `GRPO_constant`（0.441）> `MaxRL`（0.434）> `RFT`（0.413）。崩溃 run 被视为 outlier 排除后，`GRPO_constant` 与 `MaxRL` 的正常水平其实与 `Dr_GRPO` 相当。

`RFT` 不用组内相对信息、只强化所有成功样本而不惩罚失败样本，因此更容易被低质量成功样本带偏，均值偏低但较稳定。

**方差/稳定性**：`Dr_GRPO`（std≈0.012）与 `RFT`（std≈0.010）在不同 seed 下最稳定；`GRPO_constant`（0.164）与 `MaxRL`（0.160）因各含一次崩溃，标准差极大，是明显的不稳定方法。

**崩溃 seed 的说明**：`GRPO_constant/seed_4` 与 `MaxRL/seed_4` 都是明显失败的 run（`val_avg_response_length≈11`、`val_accuracy≈0.06`，训练退化为输出极短无意义文本）。这两种方法依赖 group std / group mean 归一化，当某个 batch 几乎所有序列同分（如全部失败）时，归一化分母很小会放大梯度，可能触发策略塌缩。`Dr_GRPO`（无 advantage 归一化）与 `RFT`（无 baseline、无归一化）没有崩溃，间接说明 **advantage 归一化是训练不稳定的一个来源**。

**是否需要更多调参**：`MaxRL` 与 `GRPO_constant` 因崩溃高方差，最值得调参——如减小 learning rate、对归一化分母加更大的 epsilon、或收紧梯度裁剪上限，抑制导致塌缩的异常大步长。`RFT` 均值偏低，可通过增大 `normalization_constant`（相当于更小的有效学习率）或改用 leave-one-out 均值观察是否提升。`Dr_GRPO` 均值最高且稳定，是最推荐的方法。

**结论取舍**：

- 若把训练崩溃视为**必须避免的失败模式**（即任何 seed 都不得塌缩），则应采用**含崩溃口径**，结论为 `Dr_GRPO` 最佳且最稳，`RFT` 次之，`GRPO_constant` 与 `MaxRL` 因高崩溃风险应被判定为不可靠；
- 若把崩溃视为**可排除的 outlier**（只关心正常收敛时的性能），则应采用**剔除崩溃口径**，结论为 `Dr_GRPO`、`GRPO_constant`、`MaxRL` 性能相当，`RFT` 略低。

**置信度**：无论采用哪种口径，`Dr_GRPO` 都是均值最高、方差最低（std≈0.012）、且从未崩溃的方法，是**最稳健的结论**；`Dr_GRPO` 优于 `RFT` 的差距（0.444 vs 0.413）明显大于种子间波动，结论可靠。`GRPO_constant` 与 `MaxRL` 的名次完全取决于对崩溃 seed 的处理方式，且每个方法只有 4 个 seed，要更稳妥应补充更多 seeds，并对这两种易崩方法做调参（更小 lr、更大的归一化 epsilon、更紧的梯度裁剪）后重跑，以判断其真实水平。
